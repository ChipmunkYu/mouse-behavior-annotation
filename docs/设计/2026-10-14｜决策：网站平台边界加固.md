## 范围

本轮保持 React SPA + FastAPI 模块化单体，不引入微服务、重型状态框架或新播放方案。仅处理：

1. 生产启动与显式数据库迁移的职责分离；
2. detection、identity edit、suppression 等核心接口的 OpenAPI 单一契约；
3. 上传同步磁盘 I/O 对单 worker 事件循环的阻塞，以及前端实际依赖的少量稳定错误码。

明确不修改当前完整认证 GET、下载进度、完整 Blob 和 object URL 播放方式。

## 实施原则

- 三阶段串行实施，每阶段聚焦测试、审查、记录和提交后再进入下一阶段。
- 保持现有 wire format、数据库内容、上传原子发布与失败清理语义。
- 只为可观察行为补测试，不机械扩大到全量测试。
- 本轮只做本地实现与验证，不部署标注服务器。
