# 2026-10-08｜决策：距离测量与片段比例尺继承

> 类型：当前设计
> 权威范围：视频距离标定、标注页测量和导出片段比例尺
> 关联工作项：WI-20261008-01

## 已实现

- 视频保存完整 `distance_calibration`：原视频两个参考点、厘米距离和后端计算的 `cm_per_pixel`。
- 标注页支持参考标定、拖拽测量、多条页面内测量线、清除、已有端点/已显示关键点吸附；测量线播放、暂停和逐帧时保持，切换视频或刷新后清除。
- 标注页的“行为标注”“track 修正”“参考标定”“距离测量”为四个互斥工作模式；删除标定仅在参考标定模式显示，清除测量仅在距离测量模式显示。
- 标定通过视频专用 `PUT`/`DELETE` 接口持久化；仅编辑权限可修改，不改变视频审核状态或行为/媒体修订号。
- 导出片段的 `metadata.json` 仅在原视频已标定时写入：
  ```json
  "distance_scale": {"cm_per_pixel": 0.1, "unit": "cm"}
  ```
  不继承参考点、参考距离或页面测量线。
