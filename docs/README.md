# 全站文档地图

## 权威优先级

发生冲突时，按以下顺序判断：

1. [项目术语表](../项目术语表.md)：canonical wording、状态与修订定义。
2. [需求文档](../需求文档.md)：当前产品范围和正式外部契约。
3. 现行设计：分别定义检测/审核/导出 authority 与分工模块的数据、权限和事务边界。
4. `backend/README.md`、`frontend/README.md` 和 `deploy/`：对应专业目录的实现与操作说明。
5. 计划和历史文档：只说明未来目标或回滚背景，不覆盖当前权威。

仓库外的“网站服务器文件清单”是服务器实时事实的唯一维护位置；仓库内部署和规格文档不能替代实时核验。
